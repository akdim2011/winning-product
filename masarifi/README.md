# Masarifi (مصاريفي)

Monthly expense tracker with editable categories and a savings goal. Data is stored on the device.

## Get the APK
1. Open the **Actions** tab, pick the latest **Build APK** run (or run it manually).
2. Download the `masarifi-apk` artifact, unzip it, and install `app-debug.apk` on your Android phone (allow installs from unknown sources).

The app itself is `www/index.html`.
