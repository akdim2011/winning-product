# Radar COD: النسخة المجانية (تطبيق أندرويد + موقع محلي)

اختار نيش، شوف المنتجات الأكثر طلبا فـ **Jumia المغرب** بالصور، مع نقطة من 100 وحساب الربح COD. **بلا Apify وبلا أي API مدفوع وبلا سيرفر.**

## 1) التطبيق (الأندرويد)
السكريبت كيخدم **داخل التلفون** (`public/jumia.js`)، فالطلبات كتخرج من IP ديالك المغربي، وهادشي كيقلل الحجب.

للحصول على ملف APK (من غير ما تثبت والو فكومبيوترك):
1. صاوب ريبو جديد فـ GitHub وحط فيه محتوى هاد المجلد (بما فيه `.github`).
2. من تبويب **Actions** شغل **Build Android APK** (Run workflow).
3. من بعد دقايق، فآخر الصفحة نزل **radar-cod-apk** وفك الضغط، وثبت `app-debug.apk` فالتلفون (خاص تسمح بـ«مصادر غير معروفة»).

## 2) الموقع المحلي (كومبيوتر)
Node.js (LTS) ثم `start.bat` (Windows) ولا `start.command` (Mac) ولا `npm start`، والمتصفح على http://localhost:3000. هنا فيه كذلك Amazon كمصدر ثاني.

## كيفاش كيخدم
- كل نيش عندو 4 كلمات بحث بالفرنسية (`QUERIES` فـ `public/jumia.js`)، مرتبة بالشعبية، كنخلطو نتائجهم ونحذفو المكرر.
- النتيجة كتتحفظ 6 ساعات فالتلفون، وفيه تأخير 1.2 ثانية بين الطلبات.
- `npm test` كيتأكد من الـ parser.

## مهم
- Jumia ما كتعطيش المبيعات. الترتيب والتقييمات **مؤشرات** على الطلب.
- إلا بدلات Jumia شكل الصفحة، السكريبت يوقف. الإصلاح غالبا فدالة `parseCards`.
- قراءة المواقع بالسكريبت ممكن تخالف شروطها. استعملو بقدر.
- هادي نسخة debug للاستعمال الشخصي. باش تنشرها فـ Play Store خاص توقيع (signed release) وسياسة خصوصية.
